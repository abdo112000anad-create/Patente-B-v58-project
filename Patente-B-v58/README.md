# Patente B بالعربي — v58

تطبيق Capacitor لتعلّم أسئلة القيادة الإيطالية مع النص والترجمة العربية. رقم Android لهذه النسخة هو `versionCode 58` (`58.0.0`).

## الصوت والترجمة

يستخدم التطبيق Web Speech المدمج في النظام فقط، ولا يضم محرك TTS محليًا أو نماذج صوت أو مكتبات Piper/ONNX. يطلب النطق باللغة الإيطالية `it-IT`؛ إذا لم تُظهر قائمة الجهاز صوتًا إيطاليًا مسمى، يمرر اللغة إلى محرك النظام ليختار الصوت الافتراضي بدل إيقاف النطق. وعند فشل المحرك تظهر إرشادات لتفعيل صوت إيطالي من إعدادات الهاتف. بقي النص العربي والترجمة، وأزيلت أزرار ووظيفة الاستماع العربي.

## البناء والاختبارات

المتطلبات: Node.js 22، Java 21، Android SDK Platform 36. نفّذ:

```bash
npm ci
npm test
bash ./scripts/build-android.sh
```

ينتج البناء المحلي APK تشخيصيًا موقّعًا بمفتاح debug، وليس إصدار متجر Play. تبدأ سرعة Web Speech الإيطالية عند `rate=0.8`. يرفع GitHub Actions الـ APK كـ artifact باسم `patente-b-v58-debug-apk` بعد نجاح اختبارات JavaScript وAndroid والتحقق من خدمات النطق في manifest.
